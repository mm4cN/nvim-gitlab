==============================================================================
REQUIREMENTS                                        *gitlab-requirements*

- Neovim 0.10+
- git
- glab
- GitLab Personal Access Token

==============================================================================
CONFIGURATION                                    *gitlab-configuration*

>
    require("gitlab").setup({
        glab_binary = "glab",
        gitlab_token_env = "GITLAB_TOKEN",

        default_branch = "main",
        ci_file = ".gitlab-ci.yml",

        picker = "vim_ui",
        scratch_height = 15,

        artifacts_dir = "gitlab-artifacts",
        extract_artifacts = true,
    })
<

==============================================================================
PIPELINES                                            *gitlab-pipelines*

GitLab pipeline views provide interactive navigation.

Available actions:

    <CR>    Open pipeline details
    R       Re-run pipeline
    q       Close view

Pipeline details provide access to jobs belonging to the selected
pipeline.

==============================================================================
JOBS                                                      *gitlab-jobs*

Job views expose pipeline job information and actions.

Available actions:

    <CR>    Open job details
    L       Open job logs
    A       Download job artifacts
    R       Retry job
    b       Navigate back
    q       Close view

Job details display:

- Job status
- Stage
- Ref
- Duration
- Pipeline information
- Commit information

==============================================================================
INTERACTIVE VIEWS                                      *gitlab-views*

Views are displayed in a reusable scratch window.

Navigation hierarchy:

    Pipeline List
        |
        +-- Pipeline Details
                |
                +-- Job Details
                +-- Job Logs

The 'b' key returns to the previous view.

==============================================================================
HEALTH CHECKS                                         *gitlab-health*

Standard Neovim health checks:

    :checkhealth gitlab

Plugin health command:

    :GitlabHealth

Authentication check:

    :GitlabAuth
